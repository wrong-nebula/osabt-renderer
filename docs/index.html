What you are looking at

  • Geometry. 261,813 triangles traced through a bounding-volume hierarchy built at load time. The same traversal code runs in the C reference and in the Metal compute kernels.
  • Light. A warm sun shining down the length of the atrium through the roof opening, cool sky light through the same opening, and one bounce of indirect light: six rays per pixel in total, one sample each.
  • Reconstruction. That one-sample image is noisy. OS-ABT filters it in space and time using only surface normals and depth. “Ablated” is the same pipeline with its key terms removed; “Baseline” is temporal anti-aliasing followed by an à-trous filter.

Honest limits

  • Not real time on this scene. About 0.2 s per frame (roughly 5 fps) on an Apple M1. Almost all of that is ray tracing the mesh; the filter itself costs a few milliseconds.
  • Untextured. This copy of the model has a single material and no textures, so the stone is one colour with a darker floor.
  • The first frame is rough. With no history to draw on, frame 0 is blotchy in every mode; it settles within a few frames.
  • Edges are not anti-aliased. Each pixel gets one primary ray, so silhouettes are stair-stepped, and sun edges come out softer than in the reference.
  • Dark dots along some folds and silhouettes. They are in the reference too, so they come from the ray tracing of this mesh, not from the reconstruction. Not yet fixed.
  • Display only. The blue of the visible sky and the tone curve are chosen for display and are applied identically to every mode.
